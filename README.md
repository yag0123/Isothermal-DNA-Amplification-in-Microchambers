Dear Colleague,

The codes deposited here are related to our manuscript titled "Rapid Isothermal DNA amplification in microchambers detected by fluorescence RNA aptamer transcription".
Currently, the manuscript is under preparation and before submission.
The codes are for analysis of semi-automatic microchamber fluorescence images.

2409201510_wth_analysis.ijm
This is the ImageJ Macro code file for creating ROIs around each microchambers and exporting the signal intensity values to csv text files.

250106plotIntensityHistogram.py
This is the Python code for importing the csv files and plotting the data as intensity histogram and scatter plot (ROG vs intensity).
